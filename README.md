# BlindaByte

Página para aprender ciberseguridad paso a paso, en español.

## Qué incluye
- Módulo 1: Seguridad básica (contraseñas, phishing, verificación en dos pasos, Wi-Fi).
- Módulo 2: Linux desde cero.
- Módulo 3: Redes e internet.
- Glosario de ciberseguridad con buscador y probador de contraseñas.
- Progreso guardado en el navegador (localStorage).

Próximamente: ruta Premium profesional en 6 etapas y registro con correo.

## Cómo verla en tu computadora
Abre `index.html` en el navegador. No necesita instalar nada.

## Cómo publicarla con GitHub Pages
1. Sube `index.html` y este `README.md` a la rama `main`.
2. En el repositorio ve a Settings, luego Pages.
3. En Source elige Deploy from a branch, rama `main` y carpeta `/ (root)`.
4. Espera un par de minutos y abre la dirección que te muestra GitHub.
